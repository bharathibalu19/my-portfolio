🌐 Explore the Portfolio
The portfolio is built with plain HTML, CSS, and JavaScript. It is responsive and does not require a framework, package installation, or build step.
Run locally
1. Clone this repository:
   git clone https://github.com/bharathibalu19/portfolio.git
2. Open the project folder:
   cd portfolio
3. Open index.html in your browser.
   Alternatively, start a local server:
   python3 -m http.server 8000
   Then visit http://localhost:8000.
Deploy with GitHub Pages
1. Push the portfolio files to a GitHub repository named portfolio.
2. Open Settings → Pages in the repository.
3. Under Build and deployment, select Deploy from a branch.
4. Select branch main and folder /(root), then save.
5. After deployment completes, visit: https://bharathibalu19.github.io/portfolio/
